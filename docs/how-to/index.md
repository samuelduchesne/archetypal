# How-to guides

Guides for a task you already know you need to do.

- [How to install archetypal 3](install.md): from git with the epinterface fork until v3.0.0,
  on Python 3.10 to 3.12.
- [How to migrate from archetypal 2](migrate-from-v2.md): find the replacement of each v2
  name and rewrite the frequent v2 tasks.
- [How to reduce a detailed model to an SBEM archetype](reduce-a-model.md): reduce with
  existing results or one run, check the report, and choose the layout, threshold and space
  uses.
- [How to merge an archetype to a coarser layout](merge-an-archetype.md): regroup a reduction
  from its report alone, to any layout that is not strictly finer.
- [How to check that an archetype reproduces its building](compare-results.md): compare
  the detailed model's and the archetype's results against the acceptance targets.
- [How to read a UMI template library into SBEM archetypes](read-a-umi-library.md): read a
  library, check the loss report, skip invalid templates and require a lossless translation.
- [How to write SBEM archetypes to a UMI template library](write-archetypes-to-umi.md): write
  archetypes or reductions as one library, read the loss report and use strict mode.
