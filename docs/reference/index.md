# Reference

Reference pages describe archetypal as it is, one page per part of the code or the project.

- [Removed v2 capabilities](removed.md): every archetypal 2 name, module, command and option
  that archetypal 3 does not provide, with its replacement.
- [UMI to SBEM field correspondence](umi-correspondence.md): every UMI field, its SBEM
  counterpart, the rule that translates it and its status.
- [Translation report](translation-report.md): every field of the report of what a UMI
  translation lost and assumed.
- [Reduction report](reduction-report.md): every field of the report of how an archetype was
  reduced from a detailed model.
- [Results requirements](results-requirements.md): the simulation outputs reduction reads,
  and the output objects to add for them.
- [Reduction and comparison API](api/reduction.md): `reduce`, `Reduction`, the report types,
  the errors, and `compare` with its result types, generated from the docstrings.
- [UMI translation API](api/umi.md): `read_umi`, `write_umi`, `to_umi` and the report types,
  generated from the docstrings.
- [Changelog](changelog.md): every notable change, release by release.
